Don't work when you could surf

A calendar for surf sessions in Playa Grande, Costa Rica. Subscribing to this calendar adds surf session windows to your calendar app, so you don't work when you could surf.

A window = 2 hours ± high tide Daylight only

Download .ics
Subscribe by URL instead of downloading and your calendar keeps updating as new windows appear.
02 How to subscribe
Apple Calendar / iOS
  1. Mac: File → New Calendar Subscription. iPhone: Settings → Apps → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar.
  2. Paste the feed URL.
  3. Set auto-refresh to every day.
Google Calendar
  1. Open Google Calendar on desktop.
  2. Other calendars → + → From URL.
  3. Paste the feed URL, then Add calendar.
Outlook
  1. Add calendar → Subscribe from web.
  2. Paste the feed URL and name it.
  3. Import.
Anything else
  1. Look for “subscribe by URL”, “from internet”, or “ICS feed”.
  2. Paste the feed URL.
  3. Times are in America/Costa_Rica.
